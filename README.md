# Frank Portfolio

A personal portfolio website for **Frank Garcia**, focused on nuclear engineering, computational materials, scientific computing, physics, and software development.

The site is built as a lightweight static website and is designed to be deployed with **GitHub Pages**.

## Features

- Responsive Bootstrap 5 layout
- Off-white background with burgundy/red accents
- Full-screen portfolio sections
- Responsive navigation bar
- Hero section with professional introduction
- GitHub, LinkedIn, Google Scholar, and CV links
- About / Tech Stack section
- Interactive 2×2 project card layout
- Project cards reveal descriptions and optional links on hover
- Responsive mobile layout
- GitHub Pages compatible
- No build system or framework installation required

## Tech Stack

The website uses:

- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons
- Vanilla JavaScript

Bootstrap and Bootstrap Icons are loaded through a CDN, so no local installation is required.
